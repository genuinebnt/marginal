What makes it different

Four decisions you can feel

Every one of them is architecture, not a feature flag.

◱
No merge conflicts, ever

Every keystroke compiles to an operation on a shared tree, so two people typing in one paragraph converge character by character. There is no conflict dialog because there is no conflict to resolve.

◌
Diagnostics on prose

Dangling page links, heading levels that skip, orphaned pages, code blocks with no language. Amber and advisory — a notebook has no compile step, so nothing here is ever "broken".

↶
Undo that is yours

Undo reverses your last edit, not the document's. Your collaborator's interleaved changes stay exactly where they are, because every operation carries its own inverse.

✦
An assistant that plays by the rules

The assistant proposes operations, not text. Its edits appear as a distinct author, undo like anyone else's, and never touch a document it was not asked about.

Your machine, your data

Self-hosting is not the downgrade

We run it on Google Cloud. You can run the identical build on your own machine with one compose file — same code, same features, no edition with the good parts held back.

  • Postgres for documents, object storage for images and snapshots
  • Back up with pg_dump — no proprietary export
  • Every version of every page, replayable from the operation log
  • No telemetry. Analytics, if you enable them, count published pages only
