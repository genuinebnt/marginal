Collaborative editing spec

As of op 1,284 · today, 14:06

The editor never mutates the block tree directly. Every keystroke, paste, and drag compiles to an Op, which is applied locally for instant echo and appended to the log for durability and sync.

A markdown document is parsed on every render, so two people editing it must reconcile the text itselftext. A block tree is parsed once at input time, so two people editing it apply ops to nodes. That is the whole reason live collaboration works here and merge-conflict UI never appears.

Positions are anchors, never integer offsets — a concurrent remote edit invalidates an offset but not an anchor.

◆
This view is replayed, not restored. Block rows are a projection of the log, and a test proves the projection can be rebuilt by replay. Snapshots exist for performance, never for correctness.
