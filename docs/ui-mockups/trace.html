Op 0 / 0 Backwards applies invert(op) — never a snapshot restore
Really real. Every op above is applied and inverted by code in this page, and the badge in the header re-checks apply(invert(op), apply(op, doc)) == doc on every single step. Step backwards and you are watching inverses run, not a saved copy being restored.

That only works because each op carries what its inverse needs: DeleteText keeps the removed text, DeleteBlock keeps the whole subtree, and MoveBlock keeps from as well as to. An op recorded with only its destination would make this page impossible.
