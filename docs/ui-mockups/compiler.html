What this is, and is not
This is the paste path. The pipeline is real and it is exactly what an import runs — but the editor runs all of it only on paste; on a trigger character it runs one bounded line of it against a single block; on an ordinary keypress it runs none of it — one InsertText op against the rope, and stop. The document is never re-parsed (RFC-001 §2).

The page recomputes on every keystroke because that is what makes the stages pokeable. Do not read the interaction as the hot path.
Projection check
The ops on the left are interpreted into a second block tree, and the two trees are compared field by field. If lowering and replay ever disagree, this goes red — which is the whole reason to build the check before the history phase needs it.
Offsets
Marks are stored as byte ranges. Where a block holds non-ASCII text the char range and the byte range differ, and only one of them is safe to send to a rope. Press Break the offsets to make the gap large.
