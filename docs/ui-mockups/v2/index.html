PROTOCOL crdtconvergencelamportblock-id

Every op carries a stable block id, so peers merge concurrent edits without a conflict dialog. Ordering resolves by comparing Lamport timestamps, then actor id as a tiebreak.

A rope is the wrong primitive here. What we want is a tree of addressable nodes, each one a unit of intent1.

Two people editing a tree apply operations to nodes, which converge.

Why not a rope

A rope splits and rebalances on write. Every split renumbers the offsets beneath it, so a second actor holding an offset from a millisecond ago is holding a lie. Anchors survive that; integers do not.

Every op carries a stable block id, so peers merge concurrent edits without a conflict dialog. Ordering resolves by comparing Lamport timestamps, then actor id as a tiebreak.

A rope is the wrong primitive here. What we want is a tree of addressable nodes, each one a unit of intent.

Two people editing a tree apply operations to nodes, which converge. Two people editing text apply operations to offsets, which do not.

The acknowledgement budget is 40 ms — frozen at publish; the live page's value may have moved since.

Flips lifecycle_state back to active and replays the saga forward — reindex, re-embed, reattach blobs. It does not resurrect an op log, because the op log was never deleted: deleting a page removes it from the tree, never from history.
