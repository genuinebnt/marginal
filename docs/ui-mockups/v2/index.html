Why not a rope

Why did we drop the rope?
✦

Because a rope splits and rebalances on write, and every split renumbers the offsets beneath it1. A second actor holding an offset from a millisecond ago is then holding a stale number, with no way to detect that it went stale.

The replacement is a tree of addressable nodes where every op names a stable block id2, so concurrent edits merge by comparing Lamport timestamps rather than by reconciling positions3.
